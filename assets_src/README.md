# assets_src

Source assets (`.blend`, `.gltf`, `.png`, concept art). `tools/assetc` compiles them into the
runtime formats (`.vmesh`, `.vanim`, `.vtex`) under `assets/`, which is generated and git-ignored.

All content must be original (see docs/DEVELOPMENT_PLAN.md, section 6). Record the origin of every
generated or third-party asset next to it.

Owned by the asset work package (M5). Empty for now.
